# HR Ananlytics Dashboard using Power BI
The purpose of this project is to draw information from the csv file to Power BI through the tools of visualization of Power BI. We uncovered valuable information about the attrition of employees and draw insights
and trends to see the relation and work on it.

# Objectives
- Loading the Data from csv
- Cleaning and Formatting the data.
- Creating a Dashboard of Visualizations.
- Finding useful information

# Tools used
- Power Query
- Power BI
- Visualizations

# Key insights 
- Attrition is mostly seen in the age group of 26-35.
- The attrition rate is 16.1% in employees.
- Employees with salary upto 5K has the most attrition.
